# Roadmap

- [ ] Add verified hardware results for additional PS4 firmware targets.
- [ ] Validate PS4Debug-NG scanning on real hardware.
- [ ] Improve trainer validation across maps and supported game builds.
- [ ] Validate external-storage inventory and the currently untested native controls.
- [ ] Validate the generated Ghidra importer inside Ghidra.
- [ ] Develop PS5 13.60 support when a compatible jailbreak and required debugging/payload tools become available, then validate it on hardware.

PS5 support is a future implementation, not a feature of this release. There is no promised date. See [compatibility](COMPATIBILITY.md) for the current boundary: only PS4 10.01 has been hardware-tested.
